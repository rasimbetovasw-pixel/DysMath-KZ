# DysMath KZ

Қазақ тілінде математиканы үйренуге арналған статикалық білім беру платформасы.

## Ашып көру

Сервер мен орнату қажет емес: `index.html` файлын браузерде тікелей ашыңыз.

## Құрылымы

- `index.html` — сайттың негізгі беті
- `css/style.css` — стильдер мен бейімделмелі интерфейс
- `js/script.js` — сабақтар, ойындар, баптаулар және жергілікті тапсырма интерфейсі
- `vendor/katex/` — формулаларды офлайн көрсетуге арналған KaTeX кітапханасы мен қаріптері

Тапсырма шешу аймағы әзірше жергілікті интерфейс болып табылады; оған сервер немесе ИИ қосылмаған.
